# 노래방 7번 룸 튜토리얼 (프로토타입)

혈흔 형태 분석(BPA)을 처음 접하는 사람을 위한 단방향 튜토리얼 웹 프로토타입입니다.
visionOS 앱의 튜토리얼 흐름을 미리 눌러 보기 위해 만들었습니다.

- 실행: https://quokkaki.github.io/bpa-tutorial-prototype/
- 로컬 실행: `index.html`을 브라우저로 열면 됩니다.

## 흐름

1. BPA란?
2. 사건 브리핑 (최초 출동 경찰 → 친구 진술)
3. 현장 관찰: 구역 스티커 붙이기
4. 범위 지정: 끌어서 네모로 묶기
5. 대표 혈흔: 방향 스티커 붙이기
6. 충돌각: 혈흔마다 동그라미 그리기
7. 줄 연결: 줄이 모이는 점 누르기
8. 발혈 위치: 공중에서 줄이 만나는 곳 누르기
9. 사건 보고서
10. 재연
